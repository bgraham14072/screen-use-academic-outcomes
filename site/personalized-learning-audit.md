# Personalized Instruction: Source Audit and Placement Table

Public dashboard update, November 18, 2026. The Essential Questions remain drafts for co-author review. The original register and all prior numerical additions are preserved; the new Maine row is a single reanalysis of an existing trial family, not another independent trial.

## Admission and balance

The draft adds one compatible numerical row, M2, using the reported Maine Hedges’ g and confidence interval. Mindspark remains narrative because its primary effects use baseline-test SD units rather than the existing g/d scales; North Carolina remains narrative because its reported error is on the raw-point scale and no reported g interval was verified. The latest instructions permit computed intervals, but none are calculated in this draft. No new point estimate is calculated or rounded. Narrative placement is not a quality downgrade.

Favorable, mixed and null findings use the same card component, typography, field order and source disclosures. RAND reports appear together in chronological sequence. Review findings are not averaged with primary trials, matched comparisons are not relabeled randomized, and overlapping student samples are never summed.
